# InfoEducatiePremium
Proiectul Infoeducatie Mister Premium
README – Proiect InfoEducație

Numele proiectului: Mister Premium
Secțiunea: Web
Tipul proiectului: Website educațional interactiv

Autori:
- Munteanu Tudor-Ștefan
- Tornea David-Andrei

Mister Premium este un site educațional care îi ajută pe elevi și studenți să comunice mai clar, mai sigur și mai organizat. Proiectul adresează nevoi reale: mulți utilizatori știu ce vor să transmită, dar nu știu cum să formuleze corect un e-mail, un CV, un discurs sau un răspuns de interviu.
Utilizatorul alege categoria, introduce informațiile necesare, primește o structură și poate îmbunătăți rezultatul în funcție de situația concretă. Structurile vin drept un schelet elementar, la care utilizatorul se poate raporta, eventual adăugând sugestiile personale.

Componente realizate de autori:
- Structura generală a website-ului a fost realizată în HTML.
- Designul vizual al paginilor a fost realizat în CSS.
- Funcționalitățile interactive ale site-ului au fost realizate în JavaScript.
- Sistemul de navigare între secțiuni a fost realizat de autori.
- Modulul pentru generarea și verificarea emailurilor formale a fost realizat de autori.
- Modulul pentru construirea și analizarea CV-ului a fost realizat de autori.
- Modulul pentru public speaking, inclusiv timerul și sfaturile afișate, a fost realizat de autori.
- Modulul pentru pregătirea interviurilor a fost realizat de autori.
- Secțiunea despre activități extracurriculare și Model United Nations a fost redactată și organizată de autori.
- Textele principale, exemplele educaționale și structura conținutului au fost create/adaptate de autori pentru scopul proiectului.

Componente care nu au fost realizate integral de autori:
- Fonturile utilizate provin din Google Fonts.
- Imaginea/mascota folosită în proiect nu a fost desenată integral de autori, ci creata cu ajutorul inteligentei artificiale.

Resurse externe folosite:
- Google Fonts – pentru fonturile „Sora” și „DM Mono”.
- Mascota / imaginea „premiumclanker.png” realizată de autori in Canva si generată cu ajutorul inteligentei artificiale, preluată și editată
- Browser localStorage – folosit pentru salvarea locală a drafturilor de email și CV.
- HTML, CSS și JavaScript – tehnologii standard folosite pentru realizarea proiectului.

Rolurile membrilor echipei:
- Munteanu Tudor-Ștefan a contribuit la realizarea structurii HTML, implementarea funcționalităților JavaScript, organizarea secțiunilor site-ului și testarea proiectului.
- Tornea David-Andrei a contribuit la realizarea designului CSS, redactarea conținutului educațional, alegerea elementelor vizuale și pregătirea documentației tehnice.

Observații:
Mister Premium nu este doar o pagină de prezentare, ci o consultare interactivă. Valoarea proiectului stă în faptul că oferă un șablon clar, dar nu înlocuiește gândirea utilizatorului, fiind precum o anexă în gândirea lui. Din acest motiv, proiectul funcționează ca un mentor digital, nu ca un simplu generator de texte.
